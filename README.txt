Telegram Moderator v10

Запуск:
1. Python 3.10+ (рекомендуется 3.11/3.12).
2. pip install -r requirements.txt
3. Linux/macOS: export BOT_TOKEN="токен"
   Windows PowerShell: $env:BOT_TOKEN="токен"
4. python bot.py

Настройки через переменные окружения:
BOT_TOKEN          токен Telegram-бота (обязателен)
DB_PATH           путь к SQLite (по умолчанию moderation.sqlite3)
WARNING_LIMIT     число предупреждений (по умолчанию 3)
MUTE_MINUTES      длительность мута (по умолчанию 15)
RESET_AFTER_DAYS  срок сброса нарушений (по умолчанию 7)

Возможности:
- фильтр мата и оскорблений с нормализацией кириллицы/латиницы/цифр;
- распознавание распространённой обфускации, растягивания букв и разделителей;
- команды /warns, /rules, /mute, /unmute;
- SQLite-счётчик предупреждений; после лимита — автоматический мут;
- сообщения администраторов исключены из модерации.

Важно:
Фильтр эвристический: 100% распознавание невозможно, а контекст и новые обходы
могут требовать настройки словаря. Тестируйте в отдельной группе перед включением.
Бот должен быть администратором с правами удаления сообщений и ограничения участников.
