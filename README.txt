# Telegram Moderator

## Правила наказаний
- 1-е нарушение: предупреждение.
- 2-е нарушение: предупреждение.
- 3-е нарушение: предупреждение.
- 4-е и каждое последующее нарушение: мут на 15 минут.
- Счётчик сбрасывается после 7 дней без нарушений.

## Запуск
1. Создайте бота через @BotFather и скопируйте токен.
2. Добавьте бота в группу и назначьте администратором.
3. Разрешите ему удалять сообщения и блокировать участников.
4. Добавьте переменную окружения `BOT_TOKEN` со значением токена.
5. Установите зависимости: `pip install -r requirements.txt`
6. Запустите: `python bot.py`

## На Android через Replit
1. Откройте https://replit.com и создайте Python-проект.
2. Загрузите `bot.py` и `requirements.txt`.
3. В Secrets добавьте `BOT_TOKEN` = токен от BotFather.
4. Запустите проект кнопкой Run.

Важно: для непрерывной работы нужен хостинг, который не останавливает процесс.
Бот проверяет текстовые сообщения. Для работы с сообщениями группы назначьте его администратором.
